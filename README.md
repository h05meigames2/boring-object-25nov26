# The Most Boring Object, Reviewed in One Line

A one-line review of the dullest everyday object I could name: the doorstop. The joke comes from how the object really behaves — a doorstop's entire job is to lie still on the floor holding a door open, doing absolutely nothing else, and yet every person who walks through still kicks it aside. Its own dullness is the joke: the only employee whose job is standing still, and it still gets kicked for it.

## The program

`main.py` (Python 3, standard library only, no network) holds the review as a single string, validates it (one line, 1–200 characters, not only whitespace), and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## The line

> The doorstop: the only employee whose entire job is to stand still, and it still gets kicked for it every single day.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/boring-out python3 main.py
cat /tmp/boring-out/entry.txt
```
